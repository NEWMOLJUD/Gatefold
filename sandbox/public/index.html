Experimental test project

A link shortener that scales horizontally.

Redoma Links exists to test horizontal, scalable architectures: instead of one big database, links are spread over many small ones. It is an experiment of Redoma, not a production service. Paste a long address to try it.

    How it works

    1. A code is drawn Seven random letters and digits, then one check character: k3x9ab7x. There is no counter to wait for.
    2. Six characters pick the database k3x9ab means the link is kept in links-k3x9ab. A database is created the first time it is needed.
    3. One query opens the link A visit asks that one small database, however many others exist. A mistyped address fails the check and opens no database at all.
    4. One database keeps the totals Redirects and databases in use are counted in redirect-count. It is the only thing all visits share, so a link still opens if a count cannot be saved.

    Redoma Links is the example app of Redoma. The whole server is one short file.

    It is an experiment: links may stop working at any time, and anyone who has a short link can open it. Do not shorten anything private.
