## Ajustes do projeto:
Apesar do projeto estar funcional, ele esta longe de ser um projeto open source real, e eu quero que voce torne um projeto real e confiavel, porém mantendo os limites do projeto.

## Limites:
- Nada de buckets ou coisas do genero, o projeto deve ter apenas um único banco sqlite como armazenamento.

## Problemas:
O projeto esta escrito em portugues, sendo que deveria estar escrito em inglês.

O readme deve ser intuitivo e levar o user a consseguir usar o projeto facilmente.

A interface admin esta longe de ser profissional, esta muito feia e desorganizada (deixe como um app corporativo realmente deve se parecer)

a interface de leitor também está horrível.

Isso é um template, então voce deve criar uma pasta chamada label, onde o user vai colocar as logos da empresa dele, e paleta de cores com um style.css (ja deixa um configurado) , a ideia é esse template ser usado na lógica white-label, onde o cliente muda as configs do repositorio para ficar na paleta e estilo da empresa dele.
